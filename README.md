# أعلام ترفرف | Waving Flags

تطبيق ويب تفاعلي لاستكشاف أعلام الدول ومعالمها، والاستماع إلى الأناشيد الوطنية، واختبار معلوماتك. الواجهة تدعم العربية والإنجليزية.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم أو بناء. شغّل خادمًا محليًا من مجلد المشروع:

```bash
python -m http.server 8000
```

ثم افتح <http://localhost:8000> في المتصفح. يلزم استخدام `localhost` أو HTTPS لتفعيل التخزين دون اتصال؛ فتح `index.html` مباشرة لا يفعّل Service Worker.

## الاستخدام دون اتصال

1. افتح التطبيق أول مرة مع اتصال بالإنترنت عبر GitHub Pages أو الخادم المحلي.
2. اترك الصفحة مفتوحة لحظات حتى يسجل المتصفح عامل الخدمة، ثم حدّث الصفحة مرة واحدة.
3. تصفح الدول التي تريد الاحتفاظ بمواردها. تُخزّن الصفحة والموارد التي يطلبها التطبيق، مثل صور الأعلام والمعالم وبعض ملفات الأناشيد، في ذاكرة المتصفح.
4. بعد ذلك يمكن فتح التطبيق دون اتصال. تتوفر فقط الملفات والموارد التي سبق تحميلها وتخزينها، وقد يزيل المتصفح بعض التخزين عند ضغط المساحة.

الأناشيد تُحمّل من مصادر خارجية وقد لا يخزن المتصفح كل ملف صوتي كاملًا. البيانات النصية الأساسية مضمّنة داخل التطبيق، بينما صور المعالم تأتي من ويكيبيديا.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع ملفات هذا المجلد.
2. من **Settings → Pages**، اختر النشر من الفرع `main` والمجلد `/ (root)`.
3. احفظ الإعدادات وافتح رابط Pages الذي يظهر لك.

المشروع صفحة ثابتة، لذلك لا يحتاج إلى workflow أو خطوة build. يدعم `service-worker.js` التخزين المؤقت للصفحة والموارد التي تمت زيارتها.

## الملفات

- `index.html` — التطبيق والبيانات والتنسيقات.
- `service-worker.js` — التخزين المحلي للصفحة والموارد التي سبق تحميلها.
- `manifest.webmanifest` و`icon.svg` — بيانات وأيقونة التطبيق القابل للتثبيت.
- `.nojekyll` — يضمن تقديم الملفات الثابتة مباشرة عبر GitHub Pages.
